## Current role

VIRTURA2114 is no longer the canonical present-day public definition of VIRTURA Spaceport.

The repository is preserved as a historical worldbuilding layer containing the Collapse Era, old-city material, factions, legacy route narratives, early visitor systems, and previous architectural concepts.

The current Spaceport system is being rebuilt in:

- VIRTURA-SpacePort — canonical world / station / public data layer
- SceneForge — browser 3D / WebXR runtime
- VIRTURA-Collective — team / works / collaboration layer

## What remains canon here

The following material can remain valid as historical simulation or archive:

- Collapse Era;
- Old City / ruins;
- early airlines and route fiction;
- factions and social narratives;
- legacy visitor guides;
- archived architecture;
- early Balloon / resort / cultural district ideas.

## What is no longer the default public truth

The default Spaceport should not require:

- permanent post-apocalyptic framing;
- active-consciousness population counters;
- cyberpunk role-play;
- faction membership;
- RPG task progression;
- fixed fictional prices.

These can return as special exhibitions, archive modes, or historical simulations.
