# VIRTURA 2114 / AMBIENT DESTINATIONS
## 静景航线 · 虚拟目的地长时广播

VIRTURA 2114 的空间不只用于阅读设定，也可以被停留、聆听和反复进入。

**Ambient Destinations / 静景航线** 是一组持续更新的虚拟目的地广播。每一期选择一个具体地点，以长时声音、缓慢变化的空间影像和少量环境事件构成一次“无需完成任务”的旅行。

它可以作为工作、阅读、休息、散步、VJ set 或展览空间的背景，也承担 VIRTURA 2114 世界观的持续扩建：先以图像、声音和循环动态建立地点，之后逐步发展为可漫游的 3D 场景、Gaussian Splat、实时空间与独立游戏区域。

---

## 观看方式

一条航线通常持续 **60–180 分钟**。

画面不会频繁切换，而是像在同一片区域里缓慢移动：

- 10–30 分钟保持一个主状态
- 光线、天气、维护设备、植物、远处交通缓慢变化
- 不强调人物剧情
- 不要求观众持续观看屏幕
- 声音承担大部分时间感

每一期更接近“一段可以暂时生活进去的地方”，而不是传统 MV。

## 第一阶段目的地

### 001 / 温室保护区 · Greenhouse Reserve

潮湿混凝土、低速排风系统、雨水回收槽、巨大蕨类、维护步道与漫射天光组成的长期生态保护区。

适合：深度专注、阅读、雨天、低速古典 / ambient / deep vocal。

### 002 / 静水公园 · Jingshui Park

人工湖面与城市边缘的低密度植被。远处仍能看到港区结构，但声音已经被水面和林带削弱。

适合：清晨、散步、钢琴、极简主义、field recording。

### 003 / 港区夜间候机厅 · Night Transit Lounge

几乎停运的深夜航站区。大面积水泥、自动清洁设备、零星旅客、玻璃幕墙后的远航灯。

适合：夜间工作、deep ambient、低频 drone、缓慢电子乐。

### 004 / 云层维护平台 · Cloud Maintenance Deck

高于常规居住层的设备平台。风、冷凝水、输送管线和远处城市光带构成主要景观。

适合：风声、低频电子、极简 techno ambient、长时间工作。

### 005 / 种子档案馆 · Seed Archive

位于温室保护区深部的种质与环境样本库。空间更暗、更安静，只有恒温设备和数据读取灯持续工作。

适合：夜间阅读、古典弦乐、低密度合成器、专注音乐。

## 每一期包含什么

每个目的地都对应一组可以反复复用的资产：

1. **地点设定** — 地理位置、用途、历史、材料、气候、基础设施
2. **视觉母版** — 构图、镜头、光线、材质、植物与空间密度
3. **声音母版** — 环境底噪、音乐结构、动态范围与时间段
4. **循环事件** — 风、雨、雾、灯光、设备、远处交通、植物运动
5. **长时节目单** — 60–180 分钟的状态变化
6. **生成提示词** — 图像、视频、声音与后续 3D 生成所需的结构化描述
7. **升级接口** — 可继续发展为 3D、Gaussian Splat、实时场景和可探索区域

## 视觉原则

这里的未来感不依赖大量霓虹或复杂机械，而来自**真实空间逻辑中的轻微陌生感**。

核心视觉词：

- brutalist concrete / 清水混凝土
- humid air / 潮湿空气
- diffused daylight / 漫射自然光
- overgrown but maintained vegetation / 被维护的繁茂植物
- municipal infrastructure / 市政级基础设施
- quiet megastructure / 安静的大型结构
- restrained signage / 克制的导视
- distant urban systems / 远处仍在运行的城市系统
- believable near-future / 可相信的近未来

避免：

- 过度赛博朋克霓虹
- 没有功能逻辑的科幻装饰
- 满屏 hologram UI
- 过度精致的豪华酒店感
- 植物无规律堆叠
- 纯概念图式的“宏大空壳”

## 与 VIRTURA 2114 的关系

`01_空间导览/` 保存地点本身的世界观与空间结构。

`_世界观门户/氛围频道/` 保存这些地点被“广播、观看和旅行”的方式。

两者共享同一套地点 ID，因此一次视觉实验不会成为孤立图片，而会逐步回写成可继续使用的世界资产。

## 发展路径

```text
地点设定
  ↓
静帧 / 专辑封面
  ↓
微循环影像
  ↓
1–3 小时 Ambient Broadcast
  ↓
VJ / 展览版本
  ↓
3D / Gaussian Splat
  ↓
实时漫游空间
  ↓
可组合的独立游戏世界
```

第一阶段的目标不是一次做出完整世界，而是让世界可以**持续、低成本地长出来**。
