# 温室保护区 / GREENHOUSE RESERVE
## VR2114-GB-GR-001

温室保护区位于 VIRTURA 绿带北侧，是一组由旧物流压力舱、气候实验设施和雨水处理结构改造而成的长期生态保护区。

它不是观赏性植物园，而是一座仍在工作的城市基础设施：保存种质、调节局部空气湿度、处理部分灰水、维持可食与药用植物样本，同时向居民开放有限的步行区域。

这里长期保持安静。多数时候能听见的不是音乐，而是排风、滴水、远处运输系统和植物被空气推动的声音。

---

## 空间气质

温室保护区最重要的特征不是“绿色很多”，而是**植物与基础设施已经长成同一个系统**。

你会看到：

- 大跨度清水混凝土结构
- 旧工业温室留下的层压玻璃与遮阳网
- 沿梁柱布置的冷凝水回收槽
- 被植物根系包裹但仍在使用的维护管线
- 自动灌溉、滴灌和水位传感器
- 不连续的金属检修步道
- 被修剪但明显超出最初设计尺度的蕨类与藤本
- 少量低亮度导视，没有商业广告
- 偶尔经过的维护人员与小型运输设备

这里的未来感来自“它已经用了很久，而且仍然可靠”。

---

## 历史

### 2040s — 气候缓冲设施

最初用于港区物流与实验性生态舱之间的环境缓冲。空间强调耐久、维护便利和低能耗，并不面向游客。

### 2050 — 崩溃事件后

部分运输系统停用，绿带承担更强的自维持功能。原本分散的植物样本、医疗植物和水循环模块被集中到这里。

### 重建时期

保护区逐步向公共空间开放。设计团队没有把它改造成新的“景点”，而是保留工业结构，只增加步行安全、导视和少量休息区域。

因此它同时像植物园、设备层、研究设施和城市公园。

---

## 六个主要区域

### 01 / 雨厅 · Rain Hall

入口空间。大面积屋面收集降水，水通过可见的槽道进入蓄水池。

天气变化会直接改变这里的声音：下雨时，整个大厅像一个低频乐器。

**画面关键词**：wet concrete, reflected daylight, rain chains, large ferns, shallow water.

### 02 / 蕨廊 · Fern Corridor

一条被大型树蕨和阴生植物包围的长走廊。维护风从两侧缓慢穿过，叶片始终有非常轻微的运动。

这里适合长时间停留，也是最典型的 Ambient Destinations 镜头。

### 03 / 种子档案馆 · Seed Archive

位于保护区内部的恒温样本库。公共区域只能透过玻璃看到部分储存舱与样本处理台。

声音主要来自制冷系统和读取设备。

### 04 / 雨水庭院 · Rainwater Court

灰水净化和湿地植物实验区。浅水、混凝土边界和低矮草本让空间非常开阔。

夜间只有维护灯和远处城市光进入这里。

### 05 / 高架维护步道 · Service Canopy Walk

位于树冠高度的检修通道。这里能看到温室结构、城市边缘、排风塔和运输轨道之间的关系。

它不是正式观景台，但逐渐成为居民最喜欢停留的地方之一。

### 06 / 夜间观察室 · Night Observation Room

一间靠近温室外壁的小型公共休息室。混凝土墙、长椅、自动饮水设备和整面玻璃构成全部室内元素。

凌晨时段能看到自动灌溉、维护机器人和极少量夜班人员。

## 植物系统

保护区不追求“世界各地植物大集合”，而按照环境功能组织。

### 高湿阴生层

- tree fern / 树蕨
- moss / 苔藓
- shade-tolerant vines / 耐阴藤本
- broad-leaf understory plants / 阔叶下层植物

### 水处理层

- wetland grass / 湿地草本
- reeds / 芦苇类
- floating treatment plants / 浮水净化植物

### 保存与研究层

- 药用植物样本
- 可食植物种质
- 城市耐候植物
- 极端环境适应实验株

植物被编号、记录和维护，但公共区域不会把标签做成传统科普展板；信息主要存在于低调的维护标记与可选数字导览中。

| 时间 | 状态 | 视觉 |
|---|---|---|
| 05:30–08:00 | 清晨高湿 | 玻璃冷凝、蓝灰天光、维护灯尚未关闭 |

| 20:00–00:00 | 夜间低负载 | 公共照明下降、设备声更突出 |
| 00:00–04:00 | 维护时段 | 自动灌溉、巡检车、局部灯光变化 |

最适合氛围频道的时间段是 **清晨雨后** 与 **凌晨维护时段**。

## 声音地图

基础声音从近到远分四层：

1. **近场** — 滴水、叶片、鞋底、浅水
2. **空间层** — 排风、冷凝泵、低速风机
3. **设施层** — 维护车、闸门、远处电梯
4. **城市层** — 很远的港区交通与低频结构振动

音乐进入时不应覆盖这些声音，而是像第五层空气。

## 视觉母图建议

### Shot A / Rain Hall

人眼高度，24–35mm，入口大厅向内看。前景是潮湿混凝土地面与浅水，远处大型蕨类覆盖旧工业结构。

### Shot B / Fern Corridor

50mm，低速步行视角。植物密度高，但能清晰看见结构柱、通风口和维护照明。

### Shot C / Canopy Walk

35mm，树冠高度向城市方向。画面同时出现植物、温室屋面、排风塔和远处港区。

### Shot D / Seed Archive at Night

50–85mm，隔着玻璃观看内部恒温样本库。暗部占多数，只保留少量工作灯和设备状态灯。

## 可继续发展的 3D 资产

第一批建模不需要完整温室，只需要可复用模块：

- 6m / 9m 混凝土柱网
- 层压玻璃温室屋面
- 排水槽与雨链
- 金属检修步道
- 通风百叶与低速风机
- 模块化种植槽
- 树蕨 / 苔藓 / 湿地草本三类植物包
- 低亮度导视系统
- 雨水与浅水材质

这些模块以后可以重组出雨水庭院、种子档案馆外围、疗愈区花园和其他绿带空间。

## 与世界其他地点的连接

- 向南：静水公园
- 向西：疗愈区
- 向东：教育区研究设施
- 地下物流：种子档案与港区冷链系统
- 高架维护线：连接绿带水处理与能源设施

温室保护区因此不是孤立景点，而是绿带基础设施网络的一部分。
